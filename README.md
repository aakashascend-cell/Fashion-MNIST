# Fashion MNIST Classification

A neural-network image classification project built using TensorFlow and Keras.

## Objective

Classify clothing images from the Fashion MNIST dataset into one of ten categories.

## Model

- Input: 28 × 28 grayscale image
- Flatten layer
- Dense hidden layers with ReLU activation
- Dropout for regularization
- Softmax output layer for 10 classes

## Technologies

- Python
- TensorFlow/Keras
- NumPy
- Matplotlib
- Jupyter Notebook
